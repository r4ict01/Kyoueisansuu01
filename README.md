# 算数の振り返りアプリ

小学校の算数の授業で使う振り返りフォームを作成しました。

- 課題に対するまとめを入力
- 授業前に「めざすすがた」を保存し、授業後の学習記録にも追加
- 学び方の振り返り（自分で / 仲間と / 先生と）
- 〇 / ✕ の自己評価
- 「だから次は」で学び方を選択
- 自己評価（S / A / B / C）

## 使い方

ブラウザで `index.html` を開くか、次のコマンドでローカルサーバーを起動します。

授業前に「めざすすがた」を入力して「ほぞん」を押し、授業後に振り返りを入力して「がくしゅうの　きろくをほぞん」を押すと、目標と振り返りを一つの記録として保存できます。

```bash
cd /workspaces/Kyoueisansuu01
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。
